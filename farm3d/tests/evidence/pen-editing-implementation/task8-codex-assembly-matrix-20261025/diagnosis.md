This case is RED, not a fifth matrix pass.

The node is the visibility-graph corner beside the cow-yard post near `[-1.8,-36.45]`. `route()` plans around static obstacles and has no other-cow dynamic path reservation; `updateCowTaskStep()` enforces 0.85 m separation and offers only one-step perpendicular sidesteps. Neither cow clears the shared corner. This isolates a route traffic deadlock without repeating the full browser journey or changing the nook layout.

No runtime fix is made. The correct next design must let one cow yield to a physically reachable holding route while the other passes, or otherwise plan separate executable paths, retaining the same static obstacles, 0.85 m body separation, 0.8 m/s directed speed, support, station tokens and 500-second deadline.
