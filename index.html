Hook up Bugsy's brain

Bugsy thinks with Google Gemini, using your own free API key. The key stays in this browser on this device. It's never put in the website's code or sent anywhere except Google.

  1. Go to aistudio.google.com/apikey and sign in.
  2. Tap Create API key and copy it.
  3. Paste it below and tap Connect.

Moving from another device? Connect first, then use Import backup in the Brain tab to bring your buddy's memory over.

How it trains itself

Every few messages (or when you tap Train now), it reviews the chat and your thumbs up and down, then rewrites its own rules, saves what it learned about you, and files new knowledge. Each upgrade bumps the brain version.
